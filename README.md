# Flask Student Management System

## Overview
A web application built using Flask and SQLite to manage student records.to track the daily details of the life of  student

## Features
- Add Student
- Update Student
- Delete Student
- View Student Records

## Technologies
- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap

## Installation

git clone ...
cd Flask-Student-management-system

pip install -r requirements.txt

python app.py
